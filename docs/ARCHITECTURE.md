# 架構及擴充

## 本機前端

純 HTML、CSS、ES Modules，沒有執行期第三方套件。`scripts/serve.mjs` 僅綁定 `127.0.0.1` 提供檔案及官方字卡代理端點。沒有帳戶、資料庫、雲端儲存或追蹤程式。

| 檔案 | 責任 |
| --- | --- |
| `src/model.js` | 範本、12 格資料、舊 JSON 相容、素材來源驗證 |
| `src/pagination.js` | 固定尺寸的 A4 排版、標題隨下一區塊分頁、手動分頁、跨頁移動 |
| `src/main.js` | DOM 呈現、頁碼導航、拖放、屬性、JSON／本機儲存、動畫視窗 |
| `src/stroke-service.js` | 使用者逐筆素材、來源資訊、官方查詢連結 |
| `src/moe.js` | 官方 CSV 格式驗證、已收錄單字的原始 iframe 網址 |
| `assets/moe-index.json` | 6,063 字嵌入索引及官方來源／SHA-256，不含動畫 |
| `scripts/moe-strokes.mjs` | 官方 SVG 字卡按需下載、ZIP／CRC 驗證、原圖保留、重試及記憶體快取 |
| `scripts/update-moe-index.mjs` | 從官方下載清單更新本地索引；格式變更時停止 |
| `scripts/browser-smoke.mjs` | 隔離 Chrome 配置的本機整合及列印驗證 |

## 分頁模型

使用 CSS 96 px/in 對應 210 × 297 mm。每頁頂部 23px、底部 19px、頁首依標題與抬頭欄位動態計算（詳見 0.3.2），頁首間距 8px（頁首隱藏時為 0）、頁尾 28px；其餘為內容區。`PAGE` 常數和 CSS 的固定幾何必須一起變更，並通過瀏覽器列印測試。

練習行高 54px、分組標題高 40px；單字區塊高 86px + 每 16 畫一行的 48px，缺少素材也預留一行。最多 64 畫會分成四行。預覽與列印使用同一組排版結果，區塊保持完整。頁首標題最多顯示兩行；區塊標題單行過長使用省略。分頁不依賴 `scrollHeight` 猜測。

`blocks` 保持單一有序列表。`pageBreakBefore` 表示區塊前強制分頁，頁清單是衍生結果，不另存一套頁／區塊副本。空文件呈現一張空白 A4；頁首的分頁標記不製造額外空白頁。將區塊移至另一頁會插到該頁開頭，必要時把原頁首的強制分頁界線移交給它。跨頁拖到區塊上則插在該區塊前，保留原有的手動分頁。

專案保持 `hanzi-worksheet-studio-v2` 格式，新增選用欄位，原有範例可讀取。驗證會補齊重複 ID，限制單一專案 250 個區塊。範本完整使用輸入文字，上限 240 字，超出時明確拒絕；不再默默只留下前 5／8 個字。

## 筆順與字形的兩條來源

- 官方索引既提供原始動畫的教學視窗，也供本機 API 核對按需下載字卡的單字。字帖缺字自動下載官方原始累積 SVG，接入逐筆與描紅；前端同時最多兩字，服務端請求去重、最多四字並行、64 字記憶體快取。瞬斷自動重試至多三次，失敗不快取，使用者可再試。
- 使用者匯入圖片優先於官方自動補載，避免覆蓋既有工作。公開版不再內附私人三字圖片。缺字使用裝置字型顯示整字，不產生假的逐筆內容，也不保證裝置字型符合教育部字形。

官方 iframe 只在使用者點開時載入，關閉視窗即卸載。索引更新不下載動畫，不自動擴大權利範圍。來源與授權詳見 `DATA_RIGHTS.md`。

## 後續工作

官方原始累積 SVG 字卡已按需接入；之後可擴充字形比對、更多字的真實下載驗證與來源管理。其他可選方向包含可調字格尺寸、完整印刷署名附錄、向量 PDF、字體嵌入及教材包；帳戶和雲端協作不在本輪範圍。

## 0.3.2 頁首、空白格及來源頁

`documentSettings` 統一正規化顯示標題、可選姓名／班級／日期、獨立填寫內容及空白格樣式；新舊 JSON 都可讀取。舊版預設姓名標題改為通用標題，自訂標題保留。抬頭欄位預設關閉，原有區塊的簽核設定保留，新建區塊預設不顯示簽核。

頁首由實際顯示的標題（71px）及抬頭列（24px）決定高度；全部隱藏則不產生頁首元素，分頁引擎使用同一高度計算可用空間。

單字行與連寫行共用 `cellsForRow`、格子 DOM 和編輯操作。空字、空白字元或透明度為零時統一正規化為 `{ch:"",opacity:0}`，保證空白格沒有隱藏字圖。`cellCounts` 從最終格子計算已填及空白數量，不以範本 count 猜測手動行。選取工具為預設；填字和清空是明確的工具，選取不會修改內容。

`officialCredits` 只依目前區塊實際使用的字及素材 metadata 判定來源頁。所有官方素材集中到一張文件末頁，不與練習區塊混排；頁碼導航可到來源頁，區塊移動選單僅含練習頁。預覽與 PDF 使用相同 DOM，來源頁併入輸出總頁數；純空白文件不附未使用素材來源。

## 0.4.0 編輯歷史與文字套用

`src/history.js` 的 `DocumentHistory` 保留最多 50 步文檔快照。區塊與頁首設定獨立複製；已載入的 SVG／PNG 字串與陣列按唯讀資源共享，避免每個步驟複製整份圖片庫。比較狀態時忽略選中區塊與當前頁碼，導航不產生步驟。連續同欄位修改以 750ms 間隔合併，focusout 或歷史恢復會終止合併。

所有使用者修改經 `saveLocal` 記錄。背景字卡下載使用非記錄儲存，將缺少的官方資源補入歷史各狀態，但不覆蓋該狀態已有的自行匯入資源。歷史恢復／開啟專案會遞增工作版本，過期下載與檔案讀取不可覆蓋新狀態。歷史不寫入 localStorage 或 JSON，避免圖片與編排的多份歷史導致儲存膨脹。

`sourceText` 儲存輸入草稿，新增選用 `appliedText` 記錄上次套用文字。舊 JSON 未含此欄位時從 sourceText 初始化，格式仍維持 v2。`src/text-update.js` 純函式依上一份文字辨識自動內容，保留手動行與自訂內容。重複字依各次出現的位置對應；新增單字沿用同組原有設定，設新 ID 並清除手動格與新頁標記，避免新增區塊繼承意外分頁。超過 240 字或 250 區塊時先拒絕，不部分寫入。

## 0.5.0 線上託管

`worker/index.js` 是標準 Web Request／Response 的 ESM 工廠，`worker/stroke-archive.js` 使用有大小界線的串流及 DecompressionStream 解碼。沒有 Node 原生 API，原有本機 `scripts/serve.mjs` 仍可使用。

`build-hosted.mjs` 確定性地內嵌允許對外提供的資產；伺服器源碼、Git、環境檔和工作區其他資料不列入資產。根路徑與 `/src/` 由同一 Worker 提供，筆順接口同源，不需跨站代理或瀏覽器繞過 CORS。

筆順接口限制官方索引內的單字及固定官方主機；限制每實例最多四個上游下載，64 字一小時記憶體快取，以及每實例暫存的每位訪客 120 次／分鐘。IP 僅由應用程式暫存作節流索引，不寫入應用資料庫；託管平台的基礎存取紀錄可能包含 IP。這不是跨機房全局節流。沒有文字、圖片或專案上傳接口。

`.openai/hosting.json` 保存 Sites project_id，並使用相同源碼構建／版本封裝完成發布。GitHub 源碼與 Sites 託管源碼均保留 AGPL-3.0 授權。

雲端 Fetch 使用 `redirect: manual` 並明確拒絕非成功狀態，不依賴邊緣執行環境不支援的 `redirect: error`；保留 globalThis 接收者以相容 Web API。相關行為在 hosted-worker 測試中檢查。
