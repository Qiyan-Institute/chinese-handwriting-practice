# 正體字帖工坊｜繁體字描紅與筆順練習

免費、開源、可在自己電腦使用的繁體字練習工具。支援任意文字、第一版全描紅／第二版半描紅、每行 12 格、字格及區塊拖放、灰度、家長簽核、JSON 存取、多頁 A4 編輯及瀏覽器列印。

**MVP 0.5.0 線上版**：新增最近 50 步撤銷／重做，以及草稿文字與套用到字帖的明確流程。整理乾淨版面、獨立素材來源頁、可選抬頭與簽核、精確空白格計數及選取／填字／清空工具。缺字會自動下載官方原始累積 SVG 字卡，接入「楷體逐筆」、描紅格及列印。保留 6,063 字官方索引、動畫視窗、多頁編輯及來源紀錄。程式碼採 **AGPL-3.0-only** 授權，允許依法商用；第三方字形及筆順素材另依其原始授權。公開倉庫不附私人 PDF、筆順圖或個人字帖範例。

## 線上使用

[開啟正體字帖工坊](https://qiyan-chinese-handwriting.bountifulhome1.chatgpt.site) — 公開網址，不需安裝 Node。預設範例是「孫中山」。編輯、JSON 與列印在瀏覽器執行；逐筆由同站接口按需取得。沒有帳戶或專案雲端儲存，檔案仍由使用者自行下載保存。

## 本機啟動

Node.js 18 以上，不需要 `npm install`：

```bash
git clone https://github.com/Qiyan-Institute/chinese-handwriting-practice.git
cd chinese-handwriting-practice
npm start
```

開啟 **http://localhost:4173**，或使用原有的 `啟動.command`。伺服器僅綁定本機 `127.0.0.1`。專案檔案及使用者圖片不會上傳；字帖缺少素材時，本機服務會把對應單字送到教育部字卡下載入口。請使用 npm start 或原有啟動程式；一般靜態 HTTP 服務不提供此下載 API。

## 範例：孫中山

預設練習文字為繁體「孫中山」。也可下載 [孫中山第二版字帖 JSON](examples/孫中山_第二版.json)，在編輯器按「開啟專案」匯入。範例含三個單字逐筆區塊、九行連寫練習，每行前 6 格描紅、後 6 格空白米字格；姓名、班級、日期及簽核預設關閉。

JSON 只含編排，不內嵌第三方字圖。開啟後會按需載入官方筆順；已保存的其他專案不會被這個預設範例取代。

## 使用方式

1. 輸入練習文字及頁面標題。姓名、班級、日期預設不顯示，可在「可選抬頭與簽核」個別開啟；姓名內容獨立填寫，不從練習文字推定。選擇第一版全描紅、第二版半描紅、生字或空白範本。只更改文字時，先輸入新文字，再按「更新現有字帖文字」。重新套用範本會重建編排，確認前會說明影響，套用後可整次撤銷。範本最多 240 字，專案最多 250 個區塊。
2. 內容自動排成多張 A4；用頁碼選單跳頁。分組標題會盡量跟隨下一區塊，不拆開單字逐筆區塊。
3. 點選區塊，在右欄修改文字、描紅格數、灰度或家長簽核。勾選「此區塊另起一頁」可手動分頁；「移到指定頁的開頭」可跨頁移動。也可以把區塊拖到另一頁的區塊之前。
4. 一般點字格只選取區塊。點左側字塊切到填字工具，再點字格填入；也可切換「清空字格」，或用 Shift + 點格子清空。單字行及連寫行都支援；右欄顯示實際已填／空白格數，可一鍵清空本行。空白格預設保留米字格，內部不放文字或字圖。格中的字可拖到另一格，保留原透明度。
5. 官方筆順區輸入一字，點「播放官方原始筆順動畫」。可用字依官方公開嵌入清單核對；未知字停用播放，仍可前往官網查詢。動畫需要網路，保留原貌，**不會轉成列印用筆順圖**。
6. 字帖中的官方收錄字若無本地素材，會自動下載該字的官方 SVG 字卡並填入「楷體逐筆」及描紅格；載入狀態與「重試缺字筆順」在左欄。列印會等待素材與圖片載入，失敗時先提示重試。新取得的 SVG 與來源會隨專案保存，舊專案打開後同樣自動補載。若自行持有適當授權的累積逐筆圖片，可依 `01.png`、`02.png`…批次匯入，填寫來源、授權及署名。最多 64 張，筆畫過多時分行顯示。系統不判斷筆順正確性或替你審核授權。
7. 「儲存專案」下載 JSON，包含手動分頁、字格、本地圖片及來源。可讀取原有 0.2.0 專案。「列印／另存 PDF」輸出全部預覽頁，選 A4、100%、無額外頁邊距及列印背景。

## 驗證

```bash
npm test
```

共 40 項，涵蓋原有排版、分頁、官方索引、字卡 ZIP 解析／校驗、SVG 原始 bytes、下載去重／快取／重試和來源存取。

瀏覽器整合驗證需 Node.js 22 以上及本機 Chrome，不會使用日常瀏覽器的設定或資料。預設使用明確標記的合成圖片驗證排版，不依賴私人字卡；真實官方下載可另行開啟：

```bash
npm run test:browser
# 加上真實官方字卡下載驗證：
QA_LIVE_STROKES=1 npm run test:browser
```

預設使用 macOS Chrome，可用 `CHROME_PATH` 指定其他平台的 Chrome／Chromium 執行檔。測試會啟動隔離設定檔、檢查交互及真實 PDF 頁數，輸出截圖、PDF 和報告到臨時目錄（終端會顯示路徑）。可用 `QA_OUTPUT` 指定輸出目錄；預設本地端口 4187，可用 `QA_PORT` 修改。此測試驗證嵌入網址及署名，**不宣稱教育部遠端動畫播放或音訊已自動驗證**。

## 更新官方索引

```bash
npm run update:moe-index
# 或使用已下載的官方 CSV：
node scripts/update-moe-index.mjs --input /path/to/官方清單.csv
```

僅更新字與嵌入網址的索引，不下載動畫。更新前先核對[官方版權說明](https://stroke-order.learningweb.moe.edu.tw/page.jsp?ID=52)。CSV 格式、字碼或網域不符合預期時，腳本停止並保留原有索引。

## 已知限制

- 依 6,063 字索引按需下載官方提供的 SVG 字卡，並非已預先下載完整字庫。保留原始 SVG 內容與官方署名，不由動畫拆畫或重繪。未在所有字上逐一測試；官方下載失敗時提供重試。素材用途仍依官方條款。
- 已取得字卡的字會用官方完整字形作描紅；缺少素材時仍可能顯示裝置字型。官方動畫本身不隨 JSON 打包，也不進入列印頁；累積 SVG 字卡則會保存並用於列印。
- 版面使用固定 A4 及字格尺寸；頁首標題最多顯示兩行，區塊長標題單行省略。尚無自由調整字格尺寸、獨立向量 PDF 匯出器或字體嵌入。
- 圖片會放入 JSON；瀏覽器本機空間不足時需手動下載專案。匯入檔案上限 40 MB。
- 使用官方字卡時，在文件末尾附一張「素材來源」頁統一標示教育部、來源及授權。練習頁不再重複放置授權字串及 A4 尺寸文字。純空白或未使用官方字卡的文件不附來源頁；自行匯入素材仍依各自要求補足署名。
- 無帳戶、雲端同步、團隊協作或金流。

程式碼使用 [GNU AGPL 第 3 版](LICENSE)。AGPL 允許收費及商業利用，散布與修改版網路服務須履行相應源碼提供義務；本專案未添加禁止商用條款。教育部字卡、動畫與使用者圖片不會因程式碼採 AGPL 而重新授權。詳見 [第三方素材聲明](NOTICE.md)、[資料權利紀錄](docs/DATA_RIGHTS.md) 與 [架構說明](docs/ARCHITECTURE.md)。

## 文字更新與撤銷／重做

- 左欄文字先作為草稿。狀態會提示「尚未套用」，既有字帖與列印內容保持原編排，直到按「更新現有字帖文字」。空文字不會暗中換回預設姓名。
- 更新會處理文字仍與上一份套用文字相同的自動練習行、對應單字區塊及自動連寫標題；保留原 ID、灰度、填字格數、簽核與手動分頁。手動排格行及其他自訂文字維持原樣。單字數增加時補上新區塊，減少時移除對應的多餘自動單字區塊，並顯示更新結果。
- 「重新套用範本」會重建區塊及字格，但保留頁首設定。這是單獨一步，可用頂部「撤銷」恢復整份編排。
- 清空、填字、刪除、複製、拖動、分頁、抬頭設定、套用文字、套用範本、開啟專案及手動匯入素材皆可撤銷／重做。背景官方筆順下載不佔用歷史步數。
- 編輯區快捷鍵：撤銷 `⌘/Ctrl+Z`；重做 `⌘/Ctrl+Shift+Z` 或 `Ctrl+Y`。在文字輸入框內，保留瀏覽器原生文字撤銷，可用頂部按鈕撤銷整份字帖修改。
- 歷史保留最近 50 步；同欄位 750ms 內的連續修改合併，切換欄位會分開。撤銷後的新修改會清除重做分支。歷史僅保存在本次分頁工作階段，重新整理後重置；當前字帖、文字草稿及已套用文字仍會隨本機儲存／JSON 保存。

## 託管構建

`npm run build:hosted` 產生 `dist/server/index.js`，為零依賴的 Worker ESM。前端資產、來源索引、開源聲明及「孫中山」範例打包在同一版本；只提供明確打包的檔案，不暴露 Git 或本機檔案。

線上 `/api/moe/strokes` 使用 Web Fetch／Compression Streams，與本機 Node 解碼結果逐 bytes 比對。僅允許查詢官方索引內單字，設並行限制、短期記憶體快取與暫存節流，不是任意網址代理。`/api/health` 供部署驗證。

本機驗證雲端構建：`npm run build:hosted` 後執行 `QA_HOSTED=1 npm run test:browser`。一般瀏覽器測試使用明確標記的合成圖片；真實雲端下載在發布後另行核對。
